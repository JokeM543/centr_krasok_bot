# centr_krasok_bot
AI Telegram Assistant для «Центр Красок #1»
Описание проекта: > MVP Telegram-бота, который выполняет роль умного ассистента компании. Бот общается в свободном формате (без кнопок и команд) и консультирует клиентов строго на основе собранной информации о компании, исключая «галлюцинации».

Стек технологий:
Aiogram 3.x (Асинхронная библиотека для Telegram API)

OpenAI API (Модель gpt-5.5)

Python-dotenv (Управление конфигурацией)

Что было реализовано в соответствии с ТЗ: > 1. Сбор и очистка данных: Самостоятельно изучен сайт https://centr-krasok.kz/, выделены ключевые сущности (адреса, бренды, услуги, график работы). Data-сет упакован в системный промпт.
2. Интерфейс без команд: Бот реагирует на естественный язык пользователя, создавая ощущение бесшовного AI-чата.
3. Контекст диалога: Бот помнит историю общения (последние 10 реплик) и учитывает её при генерации ответов.
4. Защита от галлюцинаций (Guardrails): Жесткие системные инструкции запрещают боту отвечать на темы, не связанные с компанией, или выдумывать факты. При выходе за рамки контекста бот перенаправляет на человека.

Инструкция по запуску: > 1. Клонировать репозиторий.
2. Установить зависимости: pip install -r requirements.txt.
3. Создать файл конфигурации и заполнить его токенами.
4. Запустить: python bot.py.
